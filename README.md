# 📊 Bitcoin Market Price Ticker

雑音を排し、シグナルだけを見るためのミニマルなビットコイン価格トラッカーです。

## 📝 概要
アルトコインのノイズに惑わされず、ビットコインのリアルタイム価格だけにフォーカスした軽量ダッシュボードです。デスクトップの片隅やサブモニターに常時表示しておく用途に適しています。

## 🚀 特徴
- ₿ ビットコインオンリーの純度100%なデータ表示
- 🕵️ クッキーや広告、トラッキングコードを一切含まないプライバシー最優先設計
- ⏳ タイムチェーンの進行に合わせたリアルタイム更新
